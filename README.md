# 🏔️ Trekking Management System

A role-based web application developed using **Flask**, **SQLite**, and **Bootstrap** for managing trekking activities.

---

## 📖 Features

### Admin
- Dashboard
- Manage Treks
- Upload Trek Images
- Approve & Assign Staff
- Manage Users
- View Bookings
- Search
- Blacklist Users

### Trek Staff
- Register & Login
- View Assigned Treks
- Manage Trek Details
- Update Trek Status & Slots
- View Participants

### User
- Register & Login
- Browse & Search Treks
- Book & Cancel Treks
- View Booking History
- Update Profile

---

## 🛠️ Technologies

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite

## 🚀 Setup

### Clone Repository

```bash
git clone https://github.com/23f2003489/Trekking-Management-App.git
cd Trekking-Management-App
```

### Create Virtual Environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS**

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
